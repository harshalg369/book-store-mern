# 📚 Book Store Management System (MERN Stack)

A full-stack Book Store Management application built using the MERN stack (MongoDB, Express.js, React, Node.js).  
This project allows users to perform CRUD operations on books with a modern and responsive UI.

---

## 🚀 Features

- 📖 View all books (List & Card view)
- 🔍 View detailed information of a book
- ➕ Add new books
- ✏️ Edit existing books
- ❌ Delete books
- 🎨 Beautiful UI with Tailwind CSS
- ⚡ Fast frontend with Vite
- 🔄 RESTful API integration

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
